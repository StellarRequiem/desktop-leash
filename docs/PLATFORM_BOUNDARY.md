# Platform boundary (batch-1 P2)

**desktop-leash is macOS-first.**

| Platform | Status |
|----------|--------|
| macOS | Supported (AX, click, type, D4 dual-control) |
| Windows / Linux | **Not supported** in this repo |

## Product wording

> desktop-leash provides arm-gated macOS desktop control for session CUA. It is not a cross-platform RPA product.

## If you need non-macOS

- Use browser-leash for web surfaces  
- Or a separate platform-specific plane (not this tree)
